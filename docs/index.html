nanoTTS 0.5B ⚡

Comparison between nanoTTS and OpenAI GPT-4o mini TTS
Github Code 🤗 Live Demo
  • Architecture: 500M encoder-decoder autoregressive Transformer.
  • Inference: Generates up to 30 seconds at 3.5x realtime and fits in 8 GB VRAM in bf16
  • Codec and output format: Stable Codec, 16 kHz mono waveform.
  • Training data: A ~12,000 hour English-only subset of Emilia-YODAS.
  • Voices: Randomly chosen, or voice cloning
